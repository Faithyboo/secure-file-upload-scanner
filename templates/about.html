About

Secure Scanner is an academic cybersecurity project focused on safe file upload handling and classification using strict validation rules.

Security Goals
  • Prevent execution of uploaded content
  • Strict extension + double-extension detection
  • Suspicious filename keyword detection
  • SHA-256 hashing for integrity and auditability
What You Can Do
  • Upload a supported file type
  • View a scan result with classification and reason
  • Review scan history and export CSV
