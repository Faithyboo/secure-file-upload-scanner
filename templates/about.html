About This Project

This Secure File Upload Scanner is built with Python Flask as part of a cyber security software engineering internship project. It validates uploads, stores scan records, supports admin controls, and provides dashboard analytics for monitoring file upload security.

  • Validation: extension, size, suspicious names, double extension checks
  • Integrity: SHA-256 hash generation and storage
  • Administration: login, dashboard, history, delete, export CSV
  • User experience: responsive Bootstrap interface with dark mode toggle
